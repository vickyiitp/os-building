## 🏛️ Kernel Roadmap & Engineering Topics

1. **Bare-Metal Bootloader**: Real Mode (16-bit) to Protected Mode (32-bit) & Long Mode (64-bit) transitions via BIOS/UEFI.
2. **Interrupt Descriptor Table (IDT)**: Programmable Interrupt Controller (PIC) remapping and hardware IRQ handling.
3. **Memory Management**: Physical Frame Allocator (Bitmap / Stack) and Virtual Memory 4-Level Paging (`CR3`).
4. **Preemptive Task Scheduler**: Timer interrupt-driven context switching and Process Control Blocks (PCB).
